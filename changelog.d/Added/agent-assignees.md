- **Assistants can set who does a task.** The MCP tools `create_tasks` and `update_tasks` take `assignees` — member ids or exact display names — and the agent REST routes (`POST /api/v1/tasks`, `PATCH /api/v1/tasks/{id}` with an `agent` token) accept the same field under the usual write switches, limits and audit; a person who is not a member of the task's project is refused with `not_a_member` (agent-assignees).
